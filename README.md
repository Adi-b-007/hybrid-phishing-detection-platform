# 🛡️ Hybrid Phishing Detection Platform

A full-stack cybersecurity platform designed to detect phishing websites using a **hybrid detection approach** that combines **URL analysis, machine learning, blacklist verification, and report generation** to improve phishing detection accuracy.

---

## 📌 Project Overview

Phishing attacks are one of the most common cyber threats used to steal credentials, financial information, and personal data.

The **Hybrid Phishing Detection Platform** provides automated detection of suspicious URLs by integrating:

- URL-based feature extraction
- Machine Learning classification
- Blacklist verification
- Website scanning
- Detection history tracking
- PDF report generation

The platform aims to assist users, students, researchers, and security analysts in identifying phishing attempts efficiently.
