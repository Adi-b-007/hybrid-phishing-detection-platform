# Hybrid Phishing Detection Platform

A cybersecurity platform that detects phishing websites using:

- Machine Learning
- Threat Analysis
- Domain Intelligence
- Risk Scoring Engine
- Browser Extension

## Technologies

- React
- Flask
- MongoDB
- Scikit-Learn
- Chrome Extension API

## Features

- URL Scanning
- Threat Analysis
- Domain Intelligence
- Risk Scoring
- Dashboard Analytics
- Browser Extension
